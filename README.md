# 建設DXコンサルタントTK ホームページ

栃木県の建設コンサルタント業・測量業向けに、ホームページ制作と業務効率化アプリ制作を訴求する静的サイトです。

## 構成

- `index.html`: ページ本体
- `styles.css`: レイアウトとデザイン
- `script.js`: お問い合わせ文面の作成・コピー
- `assets/tk-black-cat-mascot.webp`: 黒ネコキャラクター画像
- `koutei/`: 工程管理アプリ（後述）

## 工程管理アプリ（`koutei/`）

建設コンサルタントの技術職向けに、業務（プロジェクト）の工程と技術者の稼働をまとめて管理する画面です。
`koutei/index.html` を開くだけで動作し、サーバーは不要です。データは利用しているブラウザの localStorage に保存されます。

### 画面

- **ダッシュボード**: 進行中プロジェクトの遅延・注意・順調の件数、進捗バー（予定進捗との比較）、応援が必要なタスク、メンバー稼働率、期限が近いタスク
- **プロジェクト**: 業務とタスクの登録・編集、完了処理
- **ガントチャート**: 日／週／月の3段階で工程を表示。計画バーに実績進捗を重ね、本日線と予定進捗位置を表示
- **メンバー・稼働率**: 技術者ごとの割当工数、稼働可能工数、空き工数
- **完了業務**: 完了したプロジェクトの保管（進行中の一覧からは外れます）

### 判定ロジック

- タスクの**予定進捗率**は、開始日〜終了予定日の稼働日（土日を除く）に対する経過割合で算出します。
- タスク状態は「実績進捗 − 予定進捗」で判定します（5pt以上の遅れで注意、15pt以上または期限超過で遅延）。
- プロジェクト状態は、予定工数で重み付けした全体の進捗差と、遅延タスクの件数から判定します。
- **稼働率**は「残工数 ÷ 稼働可能工数」です。残工数（予定工数 ×（1 − 進捗率））を今日以降の残り期間に配分し、基準月に重なる分を集計します。期限を過ぎたタスクの残工数は当月に計上します。
- **応援候補**は、基準月の空き工数、業務分野の一致、そのプロジェクトへの参加状況から順位付けします。

### バックアップ

ヘッダーの「バックアップ」でJSONファイルを保存し、「読込」で復元できます。パソコンの入れ替えや共有時に利用してください。

## 飲食店マーケティング戦略アプリ（`inshoku/`）

飲食店の集客計画を、現状分析から毎月のやること、効果測定まで一つにまとめるアプリです。
コンサルタントが複数のお店への提案に使うことも、お店の人が自分で使うこともできます。
`inshoku/index.html` を開くだけで動作し、サーバーは不要です。データはブラウザの localStorage に保存されます。

### 画面

- **ホーム**: 目標達成に必要な1日の客数、今月のチェックリストの進み具合、直近の売上、最優先の施策
- **① 店舗情報**: 業態、立地、客単価、客層、今の集客手段、お店の特徴、困っていること、予算と時間
- **② 戦略・施策**: 強み・弱み・チャンス・注意点の整理、狙う客層、集客の流れのどこが手薄か、施策の優先順位とやること
- **②-2 競合との比較（3C分析）**: お客様・自店・競合を並べて整理。近くの競合店の価格、Google評価、口コミ件数、Instagramフォロワー、特徴を比較表とポジションマップ（価格×評価）で比べ、気づきと差別化の一文を表示。気づきは施策の優先順位と提案書にも反映
- **③ 目標の逆算**: 目標の月商から必要な客数、席の回転数、新規客の数を計算。今との差を「客数」「客単価」「両方」で埋める場合を比較
- **④ 販促カレンダー**: 月ごとの季節テーマ（栃木のいちご、宇都宮餃子祭りなどを含む）と、実行チェックリスト
- **⑤ 投稿文づくり**: Instagram、Googleビジネスプロフィール、LINE公式アカウントの投稿文と、口コミへの返信文をひな形から3パターン作成
- **⑥ 効果測定**: 売上、客数、口コミ件数、フォロワー数などを月ごとに記録し、グラフと前月比で確認
- **提案書**: ここまでの内容をA4にまとめて印刷・PDF保存

### 判定ロジック

- 施策の優先度は `inshoku/data.js` の `MEASURES` にある加点ルール（困りごと、今の対策状況、立地、客層、特徴）の合計から、予算と使える時間に合わない分を差し引いて0〜100点で出します。
- 平均客単価は、入力がなければランチとディナーの客単価をランチ客の割合で重み付けして計算します。
- 競合との比較（`inshoku/comp.js`）では、自店の評価・口コミ件数・フォロワー数を⑥効果測定の最新の記録から取ります。口コミ件数が競合平均の8割未満なら口コミ対策に加点するなど、比べた結果を施策の優先度に足します。価格の比較は、2店以上の価格がそろったときだけ行います。
- 季節テーマは `SEASON_EVENTS` に月ごとに定義しています。業態を指定したテーマは、その業態のときだけ表示されます。
- 施策の文言、点数、季節テーマを変えたいときは `inshoku/data.js` を編集してください。

## 公開前に設定すること

`script.js` の `CONTACT_EMAIL` に問い合わせ先メールアドレスを設定してください。

```js
const CONTACT_EMAIL = "info@example.com";
```

GitHub Pages では、リポジトリの Pages 設定で公開ブランチとルートディレクトリを選ぶと公開できます。
