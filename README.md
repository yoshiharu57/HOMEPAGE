# 業務日報・労務管理アプリ

建設コンサルタント向けの業務日報アプリです。
技術者が毎日「どの業務を何時間やったか」を入力し、月ごとに全員分を自動集計します。

## できること

| 画面 | 内容 |
|---|---|
| **日報入力** | 技術者・日付を選び、業務ごとの時間を入力(1日の合計も自動計算)。過去の日報の修正も同じ画面でできます |
| **月次総括表** | 技術者(20人)× 業務のマトリクスで月間時間を自動集計。CSV出力(Excel対応)あり |
| **業務別集計** | 業務ごとの合計時間・割合をグラフ付きで表示 |
| **入力状況** | 誰がどの日を入力済み/未入力かを一覧表示(総務課の未入力チェック用) |
| **マスタ管理** | 技術者・業務の追加/名前変更/無効化。終了した業務は「無効」にすれば入力画面に出なくなります |

## 必要なもの

- **Node.js**(バージョン18以上)だけです。データベースや追加ライブラリのインストールは不要です。
  - Node.js は https://nodejs.org/ja からダウンロードできます(LTS版を選んでください)

## 起動方法

1. このフォルダでコマンドプロンプト(またはターミナル)を開く
2. 次のコマンドを実行

   ```
   node server.js
   ```

3. ブラウザで http://localhost:3000 を開く

停止するときはコマンドプロンプトで `Ctrl + C` を押します。

### ポートを変えたい場合

```
PORT=8080 node server.js        (Mac/Linux)
set PORT=8080 && node server.js (Windows)
```

## 社内のみんなで使う方法(サーバー運用)

1. 社内の1台のPC(総務課のPCなど)でこのアプリを起動する
2. そのPCのIPアドレスを調べる(Windowsなら `ipconfig` コマンドで「IPv4 アドレス」を確認)
3. 各技術者は自分のPCのブラウザで `http://<そのIPアドレス>:3000` を開く
   - 例: `http://192.168.1.10:3000`
4. つながらない場合は、起動しているPCのWindowsファイアウォールで
   「Node.js」の通信(またはポート3000)を許可してください

※ サーバーPCの電源が入っている間だけ使えます。日中つけっぱなしにする運用がおすすめです。

## 最初にやること(初期設定)

1. 「マスタ管理」タブで技術者20人を登録する
2. 同じく「マスタ管理」タブで業務(案件)を登録する(業務番号は任意)
3. 各技術者が「日報入力」タブから毎日入力する

## データの保存とバックアップ

- 入力データはすべて `data/db.json` という1つのファイルに保存されます
- **バックアップはこのファイルをコピーするだけ**です(週1回など定期的なコピーをおすすめします)
- PCを入れ替えるときも、このファイルをコピーすれば全データが引き継がれます

## CSV出力(Excel集計用)

「月次総括表」タブから2種類のCSVをダウンロードできます。どちらもExcelでそのまま開けます。

- **総括表CSV** … 技術者×業務のマトリクス(月次報告にそのまま使えます)
- **明細CSV** … 日付・技術者・業務・時間・備考の全明細(独自のピボット集計をしたい場合に)

## 入力ルール

- 時間は **0.25時間(15分)単位** で入力します(例: 1.5 = 1時間30分)
- 1日の合計が24時間を超える入力はエラーになります
- 同じ日の日報を保存し直すと、その日の内容が上書きされます(修正はこの方法で)
