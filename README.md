# 建設DXコンサルタントTK ホームページ

栃木県の建設コンサルタント業・測量業向けに、ホームページ制作と業務効率化アプリ制作を訴求する静的サイトです。

## 構成

- `index.html`: ページ本体
- `styles.css`: レイアウトとデザイン
- `script.js`: お問い合わせ文面の作成・コピー
- `assets/tk-black-cat-mascot.webp`: 黒ネコキャラクター画像
- `koutei/`: 工程管理アプリ（後述）

## 工程管理アプリ（`koutei/`）

建設コンサルタントの技術職向けに、業務（プロジェクト）の工程と技術者の稼働をまとめて管理する画面です。
`koutei/index.html` を開くだけで動作し、サーバーは不要です。データは利用しているブラウザの localStorage に保存されます。

### 画面

- **ダッシュボード**: 進行中プロジェクトの遅延・注意・順調の件数、進捗バー（予定進捗との比較）、応援が必要なタスク、メンバー稼働率、期限が近いタスク
- **プロジェクト**: 業務とタスクの登録・編集、完了処理
- **ガントチャート**: 日／週／月の3段階で工程を表示。計画バーに実績進捗を重ね、本日線と予定進捗位置を表示
- **メンバー・稼働率**: 技術者ごとの割当工数、稼働可能工数、空き工数
- **完了業務**: 完了したプロジェクトの保管（進行中の一覧からは外れます）

### 判定ロジック

- タスクの**予定進捗率**は、開始日〜終了予定日の稼働日（土日を除く）に対する経過割合で算出します。
- タスク状態は「実績進捗 − 予定進捗」で判定します（5pt以上の遅れで注意、15pt以上または期限超過で遅延）。
- プロジェクト状態は、予定工数で重み付けした全体の進捗差と、遅延タスクの件数から判定します。
- **稼働率**は「残工数 ÷ 稼働可能工数」です。残工数（予定工数 ×（1 − 進捗率））を今日以降の残り期間に配分し、基準月に重なる分を集計します。期限を過ぎたタスクの残工数は当月に計上します。
- **応援候補**は、基準月の空き工数、業務分野の一致、そのプロジェクトへの参加状況から順位付けします。

### バックアップ

ヘッダーの「バックアップ」でJSONファイルを保存し、「読込」で復元できます。パソコンの入れ替えや共有時に利用してください。

## 公開前に設定すること

`script.js` の `CONTACT_EMAIL` に問い合わせ先メールアドレスを設定してください。

```js
const CONTACT_EMAIL = "info@example.com";
```

GitHub Pages では、リポジトリの Pages 設定で公開ブランチとルートディレクトリを選ぶと公開できます。
